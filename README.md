## 💎 الميزات والوحدات التقنية المدمجة

### 1. محرك البحث والترتيب الفوري (Search & Filter Engine)
- بحث فوري وسريع بالاسم، التخصص، أو الكلمات الدلالية.
- ترتيب بحسب: **الأعلى مبيعاً 🔥، الأعلى تقييماً ⭐، الأقل سعراً 💵، والأعلى سعراً 💎**.

### 2. عروض الحزم الشاملة (Bundle Deals)
- حزم تجمع 5 أدوات متكاملة بخصم يصل إلى **65%** لرفع متوسط قيمة السلة (AOV):
  * **حزمة التاجر الرقمي الشاملة** (E-Commerce Mega Pack).
  * **حزمة الشركات والمكاتب القانونية والمالية** (Compliance & Legal Suite).
  * **حزمة وكالات التسويق وصناع المحتوى** (Viral Growth Engine).

### 3. مولد شهادات التراخيص التجارية الرسمية (Commercial License Certificate PDF)
- إصدار شهادة ترخيص رسمي باسم المشتري، رقم المعاملة، وكود تفعيل مشفر (`License Key`).
- إمكانية طباعة الشهادة أو تنزيلها بصيغة PDF تثبت ملكية وحق إعادة البيع تجارياً (White-Label Rights).

### 4. رادار التسويق الجغرافي B2B في نطاق 5 كم (5KM Local Radar)
- فحص واستخراج أنشطة Google Maps القريبة من موقع المشتري.
- تحليل نوع النشاط التجاري وتوليد رسالة تسويقية ذكية مخصصة بنموذج Gemini مع زر إرسال مباشر عبر واتساب.

### 5. مكتبة المشتريات وتنزيل الأكواد المصدرية (.ZIP Generator)
- تتيح للعميل الدخول وتنزيل الكود المصدري النظيف للأداة بملف `.zip` بضغطة زر واحدة.

### 6. لوحة تحكم الإدارة الشاملة (Admin Dashboard)
- إدارة وإضافة وتعديل وحذف المنتجات، متابعة الإحصائيات والأرباح ومعدلات المبيعات.

### 7. منظومة الرعايات والبنرات الإعلانية (Ad Banners & Sponsorships)
- مساحات مخصصة لعرض إعلانات ممولة ومربحة في أعلى الموقع ووسط الكتالوج.

### 8. ودجت الدعم الفني والمستشار التقني العائم (Floating WhatsApp Support)
- زر عائم للدردشة المباشرة عبر واتساب والإجابة عن استفسارات العملاء وأسئلة الدفع والترخيص.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend**: React 18+ مع TypeScript.
- **Styling**: Tailwind CSS (واجهة عصرية متجاوبة بالكامل Desktop & Mobile بدعم RTL أصيل).
- **Icons**: Lucide React.
- **PDF Generation & Printing**: pdf-lib & CSS Print Stylesheets.
- **Maps & Geolocation**: Google Maps Platform JS API.
- **AI Engine**: Google Gemini API (لتوليد الرسائل التسويقية وصياغة المحتوى والمستندات).
- **Packaging**: JSZip لتجميع حزم الأكواد المصدرية تلقائياً للتحميل.
